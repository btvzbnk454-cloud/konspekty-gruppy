Управление качеством. Рубежный контроль № 2

На РК дают бланк с одной задачей из четырёх типов. Сравни свой бланк с бланками ниже, найди такой же и иди по решению. Если цифры в бланке другие, решай по алгоритму под вариантами: он один на все варианты этого типа.

01
Интегральный метод

Станок: сколько пользы на рубль затрат

3 варианта · ремонт +15% / +40%
формулаУк = И / Иб И = Э / (Зс·φ(t) + Зэ)
Эпроизводительность · (1 − доля простоев) · срок службы
Зсстоимость станка
Зэремонт · срок + прочие расходы (если «годовые», тоже · срок)
φ(t)поправочный коэффициент из таблицы
Алгоритм для любых цифр
  1. Метод: «интегральный, так как известны полезный эффект и все затраты на покупку и эксплуатацию».
  2. Э для обоих станков. Проценты переводим в доли: 3% = 0,03.
  3. Знаменатель: стоимость · φ(t) + ремонт · срок + прочие.
  4. И = Э / знаменатель для обоих, затем Ук = И / Иб.
  5. Вывод: Ук > 1 — лучше базового, Ук < 1 — хуже.
  6. Что если: +15% → ремонт · 1,15; +40% → · 1,4. Пересчитываешь только И оцениваемого.
Ловушки
  • +15%Это ×1,15, а не ×1,5. В одном конспекте из чата здесь опечатка.
  • «годовые»Если прочие расходы годовые, умножай их на срок службы. Если слова нет (вариант А), прибавляй как есть.
  • Таблица съезжаетВ бланке цифры стоят на строку выше подписи. Читай по порядку строк сверху вниз.
02
КС предприятия

Три вида продукции на трёх рынках

3 варианта · базовый и отчётный периоды
формулаКС = Σ αi · КСi КСi = Σ Bj · Kij αi = Vi / ΣV
KijКС вида продукции i на рынке j, из таблицы
Bjзначимость рынка: развитые страны 1 · остальные 0,7 · внутренний 0,5
αiзначимость вида продукции = доля в объёме реализации
ΔКС(КС отч / КС баз − 1) · 100%
Алгоритм для любых цифр
  1. Значимость рынков: в развитых странах самые жёсткие требования к качеству, поэтому вес 1. В остальных странах требования ниже, вес 0,7. На внутреннем рынке самые низкие, вес 0,5.
  2. КСi по каждой строке таблицы: Kij умножаем на вес рынка и складываем. Отдельно для базового и отчётного периода.
  3. αi = объём / сумма объёмов, отдельно для каждого периода.
  4. КС предприятия = Σ α · КСi для базового и для отчётного.
  5. Вывод: рост или падение в %, самый сильный вид продукции.
Ловушки
  • ПериодыБазовый и отчётный считаются отдельно, каждый со своими α. Складывать их нельзя.
  • Kij = 0Продукция на этом рынке не продаётся, слагаемое просто равно нулю.
03
Комплексный метод

Электронный микроскоп и веса по рангам

4 варианта · диаграмма · «что если»
формулаmi = (n − ri + 1) / Sn, Sn = 10 qi = (P / Pб)^E КПК = Σ mi · qi, Ук = КПК
riитоговый ранг: меньше сумма рангов → ранг 1, самый важный
E=+1больше — лучше (увеличение): q = P / Pб
E=−1меньше — лучше (габариты, масса, мощность): q = Pб / P
КПКбу базовой все q = 1, поэтому КПКб = 1
Веса · одинаковые во всех вариантахЭ1Э2Э3Э4ΣrmE
Алгоритм для любых цифр
  1. E и веса m методом рангов (таблица выше).
  2. q для всех 5 моделей относительно модели 1, до сотых.
  3. Вывод по q: где у модели 5 q > 1, она лучше базовой.
  4. КПК = Σ m·q для каждой модели, Ук = КПК.
  5. Диаграмма: осей столько, сколько показателей, фигур столько, сколько моделей. Ромб 1 — это базовая модель.
  6. Что если: меняешь одно значение модели 5, пересчитываешь её q и КПК.
  7. Базовый образец (если спросят): аналог того же назначения для тех же потребителей, обычно лидер рынка. Его показатели принимают за 1.
Ловушки
  • Меньше = лучшеДля габаритов, массы и мощности делишь базовое значение на значение модели, а не наоборот.
  • Проценты−40% → ×0,6 · +20% → ×1,2 · в 1,5 раза → ×1,5.
04
Смешанный метод

Станок: группы показателей и баллы экспертов

2 варианта · веса групп 0,5 · 0,3 · 0,2
формулаαi = Σ баллов группы / Σ всех Ki = Σ mij · qij Q = Σ αi · Ki, Ук = Q
mвес показателя в группе, дан в таблице (0,75 / 0,25; 0,5 / 0,5; 1)
αвес группы, балльный метод по таблице 2
Eпроизводительность, срок, наработка +1 · площадь, шум −1
Алгоритм для любых цифр
  1. α групп: сумма баллов строки / сумма всех баллов. Во всех вариантах 20, 12 и 8 из 40.
  2. q для 5 показателей с учётом E.
  3. K для групп назначения, надёжности и эргономики.
  4. Q = 0,5·K₁ + 0,3·K₂ + 0,2·K₃.
  5. Вывод: Q > 1 — качество выше базового. Назови, по каким группам станок лучше и по каким хуже.
Ловушки
  • Площадь и шумМеньше значит лучше, поэтому q = базовое / оцениваемое.
  • ВесаВес группы (α) и вес показателя в группе (m) — разные числа, не путай.
