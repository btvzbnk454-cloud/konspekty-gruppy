Тип 1 · 3 варианта

Интегральный метод: станок

Формула

Ук = И / Иб И = Э / (Зс·φ(t) + Зэ)
Эполезный эффект за срок службы = Пгод · (1 − доля простоев) · T
Зсединовременные затраты = стоимость станка
Зээксплуатация за срок службы = ремонт · T + прочие расходы (если они годовые, тоже · T)
φ(t)поправочный коэффициент, дан в условии; ставим, если срок службы больше 1 года
Итыс. деталей на тыс. руб.: сколько пользы на рубль затрат

Алгоритм

  1. Выбор метода. Пишешь: «Метод интегральный: известны полезный эффект (производительность) и все затраты на покупку и эксплуатацию».
  2. Э для оцениваемого и базового: производительность · (1 − простои) · срок. Проценты переводим в доли: 3% = 0,03.
  3. Знаменатель: стоимость · φ(t) + ремонт · срок + прочие.
  4. И = Э / знаменатель для обоих станков, затем Ук = И / Иб.
  5. Вывод: Ук > 1 — оцениваемый лучше базового, Ук < 1 — хуже.
  6. «Что если»: ремонт +15% → ремонт · 1,15; +40% → · 1,4; −15% → · 0,85. Пересчитываешь только И оцениваемого, Иб не меняется.
  • Ловушка 1. +15% — это ×1,15, а не ×1,5. В одном из конспектов здесь опечатка.
  • Ловушка 2. Посмотри, есть ли в строке «прочие расходы» слово годовые. Если есть, умножай на срок службы. Если нет (вариант А), прибавляй как есть, так решено в конспекте.
  • Ловушка 3. В распечатке цифры съезжают на строку вверх. Читай по порядку: производительность → простои → стоимость → ремонт → прочие → срок → φ.

Конкурентоспособность предприятия по рынкам

Формула

КС = Σ αi · КСi КСi = Σ Bj · Kij αi = Vi / ΣV
KijКС i-го вида продукции на j-м рынке (из таблицы)
Bjзначимость рынка: развитые страны 1, остальные страны 0,7, внутренний рынок 0,5
αiзначимость (вес) вида продукции = его доля в объёме реализации
ΔКС(КСотч / КСбаз − 1) · 100%

Алгоритм

  1. Значимость рынков. Обоснование: на рынке развитых стран самые жёсткие требования к качеству, поэтому вес 1. На остальных рынках требования ниже, вес 0,7. На внутреннем самые низкие, вес 0,5.
  2. КС каждого вида отдельно для базового и отчётного периода: считаем по строке таблицы, Kij умножаем на вес рынка и складываем.
  3. αi отдельно для каждого периода: объём / сумма объёмов. Сумма α = 1.
  4. КС предприятия = Σ α · КСi для базового и для отчётного.
  5. Вывод: сравни КСотч и КСбаз, посчитай изменение в %, назови самый сильный вид продукции.
  • Ловушка. Периоды между собой не складываются. Каждый период считается отдельно со своими α. В одном решении из чата их сложили, так делать нельзя.
  • Kij = 0 значит, что продукция на этом рынке не продаётся. Слагаемое просто равно нулю.

Микроскоп: комплексный метод и веса по рангам

Формулы

mi = (n − ri + 1) / Sn Sn = 1+2+…+n = 10 qi = (P / Pб)^E КПК = Σ mi · qi Ук = КПК / КПКб
riитоговый ранг показателя: самая маленькая сумма рангов экспертов = ранг 1 (самый важный)
nчисло показателей = 4
E = +1чем больше, тем лучше (увеличение): q = P / Pб
E = −1чем меньше, тем лучше (габариты, масса, мощность): q = Pб / P
КПКбу базовой модели все q = 1, поэтому КПКб = 1 и Ук = КПК

Веса во всех вариантах одинаковые

ПоказательЭ1Э2Э3Э4ΣРанг rmE

Алгоритм

  1. E для каждого показателя (+1 / −1) и веса m методом рангов (таблица выше).
  2. Единичные q для всех 5 моделей относительно базовой (модель 1). Округляй до сотых.
  3. Вывод по q: где у модели 5 q > 1, она лучше базовой; где q < 1, хуже.
  4. КПК = Σ m·q для каждой модели. Ук = КПК (так как КПКб = 1).
  5. Диаграмма: сколько показателей, столько осей; сколько моделей, столько многоугольников. Круг 1 — это базовая модель. Чем больше фигура, тем выше качество.
  6. «Что если»: меняешь одно значение у модели 5 (×1,5 / ×1,2 / ×0,6), пересчитываешь её q и КПК.
  7. Обоснование базового (если спросят): за базу берут аналог того же назначения для тех же потребителей, обычно лидер рынка. Его показатели принимают за 1.
  • Ловушка 1. Габариты, масса и мощность — показатели «меньше = лучше». Для них базовое значение делишь на значение модели, а не наоборот.
  • Ловушка 2. «Уменьшится на 40%» — это × 0,6. «Увеличится на 20%» — × 1,2. «В 1,5 раза» — × 1,5.

Смешанный метод: станок

Формулы

αi = Σ баллов группы / Σ баллов таблицы Ki = Σ mij · qij qij = (P / Pб)^E Q = Σ αi · Ki Ук = Q / Qб = Q
mвес показателя внутри группы, дан в таблице (0,75 / 0,25; 0,5 / 0,5; 1)
αвес группы, считается балльным методом по таблице 2
Eпроизводительность, срок службы, наработка: +1. Площадь, шум: −1

Алгоритм

  1. Веса групп α балльным методом: сумма баллов строки / сумма всех баллов. Во всех вариантах 20, 12 и 8 из 40, то есть 0,5 · 0,3 · 0,2.
  2. Единичные q для 5 показателей с учётом E.
  3. Групповые K: назначения, надёжности, эргономики.
  4. Обобщённый Q = 0,5·K₁ + 0,3·K₂ + 0,2·K₃.
  5. Вывод: Q > 1 — качество выше базового. Назови, по каким группам станок лучше и по каким хуже.
