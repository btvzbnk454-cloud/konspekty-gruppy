# Как устроен сайт

Сайт целиком лежит в папке `site/`:

```
site/
  index.html   — главная со списком материалов
  m/           — сами материалы
  robots.txt   — запрет поисковикам
  _headers     — тот же запрет на уровне сервера
```

Код хранится в приватном репозитории GitHub, а Cloudflare Pages сам публикует
каждое изменение, отправленное в ветку `main`.

## Подключение Cloudflare Pages (один раз)

1. https://dash.cloudflare.com → **Workers & Pages** → **Create**.
2. Внизу нажми **Continue to Pages** (классический Pages) → **Connect to Git**.
3. Подключи GitHub, разреши доступ к репозиторию и выбери его.
4. Настройки сборки:
   - Framework preset: **None**
   - Build command: *пусто*
   - Build output directory: `site`
5. **Save and Deploy**. Имя проекта станет адресом `имя.pages.dev`,
   так что лучше взять неочевидное.

## Как добавить материал или внести правку

1. Положи HTML нового материала в `site/m/`. Внутри `<head>` должна быть строка
   `<meta name="robots" content="noindex,nofollow">`.
2. В `site/index.html` допиши строку в список `MATERIALS`.
3. Сделай коммит и отправь изменения в `main` (это может сделать Claude).
   Через минуту Cloudflare обновит сайт, адрес не меняется.

## Насколько это приватно

- Репозиторий приватный: код и материалы на GitHub видишь только ты.
- Поисковики сайт не индексируют, найти его можно только по ссылке.
- Ссылку может переслать любой, кто её получил. Если нужно строже, в Cloudflare
  можно включить **Access**: вход по коду на почту, только для адресов из списка.

## Посмотреть сайт у себя на компьютере

Запусти `serve.ps1` и открой http://localhost:8080
